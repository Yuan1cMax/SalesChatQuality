# 评价维度

## 响应速度

仅使用相邻的“买家 → 售前”消息配对。初版默认规则为 `<=10` 秒“正常”，`>10` 秒“回复慢”；报告同时保留原始时间戳和计算秒数。阈值由 `--slow-threshold` 或 MCP 参数覆盖。若中间存在连续买家消息，说明配对假设并避免重复计分。

## 回复质量

每个维度使用“通过 / 不通过 / 无法判断”，必须引用证据消息：

1. **需求理解**：是否回应用户实际问题，而不是泛泛回复。
2. **信息准确**：规格、流程、库存或服务承诺是否有明确依据；不确定时应说明需核实。
3. **价格与费用**：报价、单位、运费/附加费、优惠条件是否清楚，避免模糊或前后矛盾。
4. **下一步引导**：是否给出可执行的下一步，例如确认数量、提供链接或说明下单方式。
5. **语气与合规**：礼貌、克制，不泄露不必要的隐私，不作无法兑现的承诺。
6. **问题覆盖**：用户提出多个问题时，是否逐项回答；未回答项要列明。

## PPTX 最小字段

封面写明查询范围和生成时间；摘要页给出会话数、可计算回复数、平均/最大响应秒数和需关注数量；每个会话页放原始截图、会话元数据、逐条评价和改进建议；末页列出评分口径、已知限制和证据目录。敏感字段脱敏时须在页脚标注“已脱敏”。
